How to use this page

  1. Create a Firebase project (or use an existing one) and enable the authentication providers you want to test.
  2. Copy firebaseConfig.sample.js to firebaseConfig.js in this folder and paste your Firebase web app config values.
  3. Serve this folder locally (e.g. with npx serve test) so the Firebase SDK can run. Opening the file directly won’t work due to module imports.
  4. Use the forms above to register, sign in, and sign out. Watch the console for additional debug output.
